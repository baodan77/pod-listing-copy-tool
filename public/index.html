Etsy → Shopify POD 定制礼品文案工具

填 5 组 Etsy → 可先保存输入草稿，下次登录一键回填；再生成无连字符 SEO 标题 + 五点描述，结果也可保存并删除。

怎么用

  1. 每组填：链接 + 标题 + 卖点（可定制项、收礼人、场合、材质）。
  2. 点「保存当前输入」：把表单草稿存到服务器；下次登录可在「输入草稿库」一键回填或删除。
  3. 点「生成」：输出 5 个无 - 等符号的英文标题，以及 1 段五点英文描述。
  4. 复制英文，或「一键保存本条结果」后在「已保存结果」回看；每条可单独删除。
POD 标题：窄词靠前；标明 Personalized / Custom；Gift 与场合清晰；标题不用连字符、斜杠等符号。OpenAI API Key 填在 Render / 本地环境变量 OPENAI_API_KEY，不在网页上填。

生成规则（POD）

  • 标题：窄受众 + Personalized/Custom + 品类 + Gift/场合；不加 - / | 等符号
  • 约 70 字符内放清核心信息；可重复关键词但 5 条结构不同
  • 描述五点：可定制项 → 收礼人情感 → 材质 → 场合 → 纪念品感
  • 不写时效、稀缺、买家秀；版权 IP 图案不做
